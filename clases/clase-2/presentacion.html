Fundamentos

¿Qué es Pandas?

Biblioteca en Python para el tratamiento de Panel Data: tablas etiquetadas, limpieza, agregación y análisis.

AtributoDetalle
Open sourceComunidad activa y licencia permisiva
API estándar DSIntegrable con NumPy, Matplotlib, scikit-learn
EscalableDe CSVs locales a datasets grandes

Múltiples casos de uso

¿Para qué sirve?

#CasoQué haces
01Stocks (TSA)Series de tiempo, retornos, ventanas móviles
02Ventas (AGG)Agregaciones por canal, región, campaña
03Salud (LG)Cohortes, indicadores, seguimiento temporal
04ClientesSegmentación RFM, churn, lifetime value
En la práctica: Pandas simplifica estadística descriptiva, limpieza y preparación: el 80% del trabajo antes del modelo.

Dato curioso

2008

Wes McKinney creó Pandas mientras trabajaba en AQR Capital para analizar datos financieros.

El nombre viene de Panel Data, y también de “pandas”, porque son lindos. Hoy es una de las librerías más descargadas de PyPI.

Selecciones

ObjetivoCódigoNotas
Una columna (Serie)df["new_deaths"]Retorna Serie
Varias columnasdf[["date", "new_cases"]]Doble corchete → DataFrame
Fila por etiquetadf.loc[100]Usa el índice
Fila por posicióndf.iloc[0]Posición 0, 1, 2…

loc vs iloc: loc = etiquetas. iloc = posición entera. Confundirlos genera bugs tras un reset_index.
