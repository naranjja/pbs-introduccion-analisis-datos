Concepto clave

Referencias vs copias

Misma referencia


a = [1, 2, 3]
b = a
b.append(4)
# a y b: [1, 2, 3, 4]

Copia independiente


a = [1, 2, 3]
c = a.copy()
c.append(5)
# a intacta; c tiene 5
Regla de oro: == compara valor; is compara identidad. Con mutables, asignar (b = a) comparte el objeto.

Manejo de errores

EAFP en la práctica


try:
    x = a / b
except ZeroDivisionError:
    print("división entre cero no permitida")
except TypeError:
    print("tipos incompatibles")
Pythonic: Easier to Ask Forgiveness than Permission. Intenta la operación y captura el error, en vez de validar todo de antemano.
