# Introducción al Análisis de Datos

Material del **Programa Ejecutivo en Data Science** para las sesiones de introducción a Python y Pandas.

Este repositorio es para estudiantes: aquí están las clases listas para abrir, estudiar y practicar.

## Cómo empezar

1. Entra a la carpeta [`clases/`](clases/).
2. Abre la sesión que corresponda (`clase-1` o `clase-2`).
3. En cada sesión encontrarás dos archivos principales:

| Archivo | Qué es |
|---------|--------|
| `presentacion.html` | Diapositivas de la clase (ábrelo en el navegador) |
| `codigo.ipynb` | Notebook práctico (ábrelo en Jupyter o Google Colab) |

### Presentación

- Abre `presentacion.html` con doble clic o arrástralo a Chrome / Firefox / Safari.
- Navega con flechas del teclado o los controles de la diapositiva.
- Necesitas conexión a internet la primera vez (fuentes e íconos se cargan desde CDN).

### Código

- Abre `codigo.ipynb` en Jupyter Notebook / JupyterLab / VS Code / Google Colab.
- Ejecuta las celdas en orden, junto con la presentación.
- En la clase 2, ajusta `DATA_PATH` si tus CSV no están en `./data`.

## Estructura

```
clases/
  clase-1/          # Sesión 1 · Introducción a Python
    presentacion.html
    codigo.ipynb
  clase-2/          # Sesión 2 · Análisis de Datos con Pandas
    presentacion.html
    codigo.ipynb
  shared/           # Recursos internos del curso (no modificar)
```

## Importante: carpeta `shared/`

La carpeta [`clases/shared/`](clases/shared/) contiene estilos y utilidades compartidas entre presentaciones y notebooks.

**No la edites ni la borres.** Si se modifica, las diapositivas y el formato del notebook pueden romperse.

Trabaja solo dentro de `clase-1/` y `clase-2/` (y en tus propias copias o notebooks de práctica si lo deseas).
